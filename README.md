# Eyego App 🚀

A simple Node.js web application with an API that returns **"Hello Eyego"**, containerized using **Docker**, deployed using **Kubernetes (EKS)**, and automated with **GitHub Actions CI/CD**.

---

## 📦 Features

- ✅ Simple REST API (GET `/`)
- ✅ Dockerized (lightweight Node.js image)
- ✅ Kubernetes deployment (2 replicas, LoadBalancer service)
- ✅ CI for build/test using GitHub Actions
- ✅ Optional: CD to AWS EKS or any Kubernetes cluster
- ✅ Ready for cloud migration (GCP / Alibaba Cloud)
